Meta API: #132012 / #132001

بۆچی نامەی ئۆتۆماتیکی (OTP، پەسەندکردن و ڕەتکردنەوە) لە وەتسئاپ دەرناچێت؟

• #132001: Template name does not exist (ناوی تێمپلەیت لەگەڵ زمانی هەڵبژێردراو لە Meta یەکناگرێتەوە)
• #132012: Parameter format does not match (ژمارە یان فۆرماتی پارامیتەرەکانی {{1}} تا {{4}} جیاوازە لەوەی لەناو Meta Manager دروستکراوە).

✓ چارەسەری ١: کۆدی OTP ناچالاک کرا بۆ ئەوەی خەڵک لە کاتی بەشداربوون لە ماڵپەڕ گیر نەخۆن، کۆدی OTP ناچالاک کراوە تا بتوانن بەبێ کۆد ناوی خۆیان و هاوڕێکانیان بنووسن و پارە بدەن.
✓ چارەسەری ٢: ناردنی نامە بە یەک کرتە (1-Click) لە بەشی ناونووسینەکان کاتێک پەسەندکردن یان ڕەتکردنەوە دادەگریت، پەنجەرەی وەتسئاپ دەکرێتەوە و نامە ئامادەکراوەکە لەگەڵ شوێنی کۆبوونەوە بە یەک کلیک دەنێردرێت بۆ کڕیار.
