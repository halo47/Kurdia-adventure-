# KURDIA ADVENTURE — پلانی پەرەپێدانی ماڵپەڕی سەرەکی و فرە-گەشتی (Multi-Trip Showcase & Cinematic Motion)

نوێکردنەوەی پەڕەی سەرەکی (`index.html`) و بەستنەوەی بە کۆنترۆڵ سەنتەر بە شێوەیەک کە هەموو ئەو گەشتانەی پۆستیان دەکەیت (چەندین گەشتی داهاتوو پێکەوە) بە دیزاینێکی سەرنجڕاکێش لە بەشی «گەشتەکانی داهاتوو» و بەشی «بەشداری گەشت» پیشان بدرێن، لەگەڵ کاراکردنی ئەنیمەیشنە سینەماییەکانی GSAP، Lenis، Three.js، Anime.js، AOS، ScrollReveal، Lottie، Motion.dev و کاریگەرییەکانی Aceternity UI / 21st.dev / React-Bits.

## User Review & Critical Decisions

> [!IMPORTANT]
> تکایە سەیری ئەم بڕیارە سەرەکییانە بکە پێش جێبەجێکردن و دوگمەی **Proceed** داگرە بۆ دەستپێکردن:

- **پیشاندانی چەندین گەشتی داهاتوو (Multi-Trip Display)**: لە جیاتی ئەوەی تەنها یەک گەشت پیشان بدرێت، هەر چەند گەشتێک بڵاو بکەیتەوە (لە Cloud CMS یان کۆنترۆڵ سەنتەر)، هەموویان لە بەشی «گەشتەکانی داهاتوو» لە پەڕەی سەرەکی وەک کاردی پێشکەوتوو (بە وێنە، بەروار، نرخ، شوێن، ڕێژەی پڕبوونی کورسی، و دوگمەی ڕاستەوخۆی بەشداریکردن بۆ هەمان گەشت) پیشان دەدرێن.
- **پاشبنەمای سێ ڕەهەندی نەرم بەبێ سێگۆشە (Clean Three.js Atmosphere)**: لابردنی تەواوی شێوە ئەندازەییەکان (سێگۆشەکان) لەسەر وێنەی سەرەکی، و دانانی تەنها گەردیلەی ڕووناکی و ئەستێرەی زۆر نەرم و سینەمایی لە پاشبنەما بە Three.js.
- **ئەنیمەیشن و کاریگەرییە مۆدێرنەکان**: بەکارهێنانی Spotlight Cards (Aceternity / 21st.dev)، Border Beam Shimmer، Shiny Text (React-Bits)، خلیسکانی نەرم (Lenis)، دەرکەوتنی قۆناغ بە قۆناغ (GSAP ScrollTrigger + AOS + ScrollReveal)، و ژماردنی زیندووی ئامارەکان (Anime.js + Motion.dev).
- **چاککردنی هەڵەی OneSignal لە ژینگەی تاقیکردنەوە**: پاراستنی کۆدی OneSignal بە شێوەیەک کە لەسەر دۆمەینی فەرمی کار بکات و لەسەر ژینگەی تاقیکردنەوە هیچ هەڵەیەک (Console Error) دروست نەکات.

## 1. Overview & Core Concept

- **What It Does**: گۆڕینی بەشی «گەشتی داهاتوو» لە تاکە کاردێکەوە بۆ سیستمێکی داینامیکی فرە-گەشت (Multi-Trip Grid / Carousel) کە هەموو گەشتە چالاک و داهاتووەکان پیشان دەدات، و ڕازاندنەوەی ماڵپەڕی سەرەکی بە بەرزترین ئاستی ئەنیمەیشن و گرافیکی مۆدێرن.
- **Target Audience / Persona**: گەشتیاران و شاخەوانان کە سەردانی ماڵپەڕی KURDIA ADVENTURE دەکەن لەسەر مۆبایل و کۆمپیوتەر بۆ بینینی هەموو گەشتە بەردەستەکان و تۆمارکردنی ناویان.
- **Key Value**: بەشداربوو دەتوانێت لە یەک کاتدا چەندین گەشتی جیاواز ببینێت، بەروار و نرخیان بەراورد بکات، و بە یەک کلیک لەسەر هەر گەشتێک ڕاستەوخۆ بچێتە سەر فۆڕمی تۆمارکردنی هەمان گەشت.

---

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **بینینی گەشتەکانی داهاتوو لە پەڕەی سەرەکی**: بەکارهێنەر لە بەشی «گەشتەکانی داهاتوو» لیستی هەموو گەشتە چالاکەکان دەبینێت (هەر گەشتێک بە وێنە، دۆخی کراوە/پڕبوون، ژمارەی کورسی ماوە، بەروار، نرخ و شوێن).
  2. **هەڵبژاردنی گەشت بۆ تۆمارکردن**: بە کلیککردن لەسەر دوگمەی «بەشداری بکە» لەسەر هەر کاردێک، بەکارهێنەر دەچێتە بەشی تۆمارکردن و ئەو گەشتە بە شێوەی ئۆتۆماتیکی لە لیستی هەڵبژاردنی گەشت (`select`) دیاری دەکرێت.
  3. **زیادکردنی چەندین گەشت لەلایەن ئەدمینەوە**: هەر کاتێک لە کۆنترۆڵ سەنتەر یان لە سێرڤەر چەند گەشتێک پۆست بکەیت، دەستبەجێ هەموویان لە پەڕەی سەرەکی ڕیز دەبن.
- **Visual Identity & Theme**:
  - *Aesthetic Direction*: شێوازی تاریکی سینەمایی شاهانە (Deep Obsidian & Crimson Glow) گونجاو لەگەڵ سروشت و چیاکانی کوردستان.
  - *Color Palette & Mood*: پاشبنەمای `#07070b`، ڕووی کاردەکان `#0c0d13`، ڕەنگی سەرەکی براند `#a91d37` و درەوشانەوەی `#e5234f`.
  - *Typography & Hierarchy*: فۆنتی `Noto Sans Arabic` بە کێشی قورس (`800`/`900`) بۆ ناونیشانەکان و ژمارەی ڕێک (`tabular-nums`) بۆ نرخ و بەروار و کورسییەکان.
  - *Component Styling & Layout*: کاردەکانی گەشت بە شێوازی Spotlight Card و Border Beam لەگەڵ هێڵی پێشکەوتنی کورسییەکان (Seat Capacity Progress Bar).
- **Interactive Feedback & Motion**:
  - **Lenis + GSAP ScrollTrigger**: خلیسکانی نەرم و جووڵەی پارالاکس لەسەر وێنەی سەرەکی.
  - **AOS + ScrollReveal.js**: دەرکەوتنی نەرمی کاردی گەشتەکان، شوێنەکان، سەلامەتی و گەلەری کاتی خوارەوە هاتن.
  - **Anime.js + Motion.dev**: ژماردنی زیندوو بۆ ئامارەکان، کورسییەکان و کاتژمێری پێچەوانە (Countdown)، لەگەڵ کاردانەوەی نەرم لەسەر دوگمەکان.
  - **Three.js + LottieFiles**: گەردیلەی ئەستێرەیی نەرم لە پاشبنەما و هێمای زیندوو لەسەر کاردە چالاکەکان.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: گۆڕینی پێکهاتەی گەشت لە تاکە گەشتەوە بۆ لیستی گەشتەکان (`trips[]`)**
  - *Chosen Approach*: پاڵپشتیکردنی لیستی تەواوی گەشتەکان (`data.trips`) لەگەڵ پاراستنی گونجاوی بۆ کۆنترین داتای تاکە گەشت (`data.trip`)، تاکو چ ١ گەشت پۆست بکەیت چ ١٠ گەشت، هەموویان بە ڕێکوپێکی پیشان بدرێن.
  - *Why*: ڕێگەت پێدەدات لە هەمان هەفتە یان مانگدا چەندین گەشتی جیاواز بڵاو بکەیتەوە بێ ئەوەی گەشتی پێشوو بسڕێتەوە.
- **Decision 2: پاراستنی خێرایی و پاکی دیمەنی سەرەکی (Hero)**
  - *Chosen Approach*: بەکارهێنانی گەردیلەی ڕووناکی نەرم لە پاشبنەما بەبێ هیچ شێوەیەکی ئەندازەیی یان سێگۆشە لەسەر وێنەی چیاکان.
  - *Why*: وێنە سروشتییەکان و ناونیشانی سەرەکی بە تەواوی ڕوون و سەرنجڕاکێش دەمێننەوە.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    Cloudflare Worker / Admin CMS State                  │
│          (data.trips = [ Trip 1, Trip 2, Trip 3, ... ], i18n)           │
└───────────────────────────────────┬─────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                     Public Website Engine (index.html)                  │
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ 1. Hero Section (GSAP + Lenis Parallax + Lottie + Clean Three.js) │  │
│  └───────────────────────────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ 2. Multi-Trip Upcoming Showcase (#homeTripsGrid)                  │  │
│  │    ├─ Featured Primary Trip Card (Border Beam + Countdown + Stats)│  │
│  │    └─ Additional Upcoming Trip Cards (Spotlight + Capacity Bar)   │  │
│  └────────────────────────────────┬──────────────────────────────────┘  │
│                                   │ Click "بەشداری بکە (Select Trip)"   │
│                                   ▼                                     │
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ 3. Booking Page (#booking)                                        │  │
│  │    ├─ All Upcoming Trips List (#tripList)                         │  │
│  │    └─ Pre-selected Trip in Wizard Dropdown (#bookingTrip)         │  │
│  └───────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────┘
```

- **Data Model & State**:
  - `data.trips`: لیستی گەشتە بڵاوکراوەکان؛ هەر گەشتێک پێکدێت لە (`id`, `title`, `location`, `date`, `time`, `price`, `capacity`, `booked`, `desc`, `imageUrl`, `published`, `status`, `i18n`).
  - فلتەرکردنی ئۆتۆماتیکی بۆ پیشاندانی هەموو ئەو گەشتانەی کە چالاکن (`published !== false` و `status !== 'closed'`).
- **Interactive Component & State Mapping**:
  - فرمانی `selectTripForBooking(tripTitleOrIndex)`: کاتێک بەکارهێنەر لە پەڕەی سەرەکی کلیک لەسەر هەر گەشتێک دەکات، دەچێتە پەڕەی `#booking` و ئەو گەشتە لەناو فۆڕمەکەدا دیاری دەکرێت و بە ئەنیمەیشن سەرنجی دەخرێتە سەر.
  - نوێکردنەوەی هەڵبژاردەی زمان (`ku`, `ar`, `en`): ناوی هەموو گەشتەکان بەپێی زمانی هەڵبژێردراو دەگۆڕێت.
