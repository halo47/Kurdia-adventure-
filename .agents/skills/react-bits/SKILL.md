# React Bits — Animated Interactive UI Patterns

## Component Categories & Patterns
1. **Text Animations:**
   - Split-word/character staggered reveals, blur-to-sharp entrance (`filter: blur(8px)` -> `0px`), gradient shimmer text, and kinetic counters.
2. **Interactive Cards & Surfaces:**
   - Cursor-tracking radial spotlight cards (`--mouse-x`, `--mouse-y`), 3D perspective tilt with specular glare, and glassmorphic border glow.
3. **Micro-Interactions & Controls:**
   - Magnetic CTA buttons, elastic ripple feedbacks, animated tab indicators, and smooth accordion/drawer height transitions.
4. **Atmospheric Backgrounds:**
   - Subtle aurora/radial mesh glow, floating depth particles, and GPU-friendly ambient shaders that respect `prefers-reduced-motion`.
