# Impeccable — Design Vocabulary & Review System

## Core Workflow Commands
1. **`/impeccable init`**
   - Establishes durable product truths in `PRODUCT.md` and design tokens in `DESIGN.md` (target audience, RTL Kurdish Sorani typography, luxury dark mountain expedition theme).
2. **`/impeccable critique [target]`**
   - Read-only diagnostic review evaluating visual hierarchy, information architecture, spacing ratios, typography contrast, RTL alignment, mobile touch targets (`>=44px`), and cognitive load.
3. **`/impeccable polish [target]`**
   - In-place elevation of an existing UI surface: refines micro-spacing, optical alignment, border specular opacity, contrast ratios, and interactive states without breaking layout architecture.
4. **`/impeccable craft [target]`**
   - Full shape-then-build lifecycle: reads product/design context, maps layout hierarchy, builds production-grade components, and validates responsive/RTL edge cases.

## Deterministic Anti-Pattern Checks
- Eliminate "status-chip soup" (too many competing pills/badges in a single card).
- Prevent uniform gray text with poor contrast on dark glass surfaces.
- Prevent cards nested inside cards with redundant borders and padding.
- Enforce clear primary vs secondary action hierarchy in every viewport.
