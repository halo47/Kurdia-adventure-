# Taste Skill — Anti-Slop Frontend & Art Direction Framework

## 1. Tunable Dials
- `DESIGN_VARIANCE`: Controls structural boldness vs convention (High for KURDIA ADVENTURE luxury outdoor aesthetic).
- `MOTION_INTENSITY`: Controls kinetic hierarchy, spring physics, and scroll-linked storytelling.
- `VISUAL_DENSITY`: Balances editorial breathing room with high-utility controls.

## 2. Core Anti-Slop Mandates
- **No Generic AI Layout Tropes:** Avoid default uniform 3-column feature grids without visual hierarchy, thoughtless sticky banners, or nested cards-inside-cards.
- **No Cliché Typography:** Avoid generic fallback stacks when expressive display/Kurdish typography (`Noto Sans Arabic`, `Vazirmatn`, `Cinzel`, `Plus Jakarta Sans`) is established.
- **Borders & Depth:** Never use muddy drop shadows (`rgba(0,0,0,0.3)`) or flat 1px solid gray borders. Use micro-hairlines (`1px solid rgba(255,255,255,0.08)` to `rgba(216,27,60,0.28)`), subtle inner specular highlights, and atmospheric depth.
- **No Fake Elements:** Never use placeholder text or dummy records when real application state or Kurdish copy applies.

## 3. Spatial Rhythm & Typography
- Pair high-contrast display headings with disciplined line lengths (`55ch–70ch`) and generous line-height (`1.65–1.85`) for Kurdish Sorani RTL legibility.
- Use asymmetrical focal points, bento compositions, and intentional negative space.

## 4. Purpose-Driven Motion
- Ban linear or robotic `ease-in-out` snaps. Use spring easing (`cubic-bezier(0.22, 1, 0.36, 1)` and `cubic-bezier(0.16, 1, 0.3, 1)`).
- Ensure thumb-friendly mobile interactions and clean `prefers-reduced-motion` fallbacks.
