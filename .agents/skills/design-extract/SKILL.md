# Design Extract — Design System & Token Extraction Skill

## Capabilities & Output Artifacts
1. **Design Tokens (W3C DTCG & CSS Variables):**
   - Extracts primary/accent palettes, surface elevation layers, glassmorphism blur/opacity tokens, border radii, and shadow elevations.
2. **Typography System:**
   - Captures font families, weight distributions, fluid `clamp()` scales, line heights, and RTL/LTR directional rules.
3. **Component & Layout Signatures:**
   - Documents navigation bars, hero compositions, trip/product cards, modal sheets, form controls, and micro-interaction states.
4. **WCAG Accessibility Audit:**
   - Evaluates foreground/background contrast ratios, focus ring visibility, and mobile tap target sizing.
